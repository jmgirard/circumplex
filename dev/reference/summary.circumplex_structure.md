# Summarize circumplex-structure test results

Fuller display of a
[`fit_structure()`](http://circumplex.jmgirard.com/dev/reference/fit_structure.md)
object: adds the interpretive cutoffs behind each classification, the
estimated angle and communality of each scale, and the analysis
settings.

## Usage

``` r
# S3 method for class 'circumplex_structure'
summary(object, digits = 3, ...)
```

## Arguments

- object:

  A `circumplex_structure` object.

- digits:

  The number of decimal places to display (default = 3).

- ...:

  Not used.

## Value

`object`, invisibly.
