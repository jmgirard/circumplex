# Display the items of a circumplex instrument

Display the items of a circumplex instrument including the total number
of items and each item's number and text. The item ordering/numbering
displayed here is the same ordering/numbering assumed by the
[`score()`](http://circumplex.jmgirard.com/dev/reference/score.md)
function.

## Usage

``` r
items(x)
```

## Arguments

- x:

  Required. An object of the instrument class.

## Value

The same input object. Prints text to console.

## See also

Other instrument functions:
[`anchors()`](http://circumplex.jmgirard.com/dev/reference/anchors.md),
[`instruments()`](http://circumplex.jmgirard.com/dev/reference/instruments.md),
[`norms()`](http://circumplex.jmgirard.com/dev/reference/norms.md),
[`scales()`](http://circumplex.jmgirard.com/dev/reference/scales.md)
