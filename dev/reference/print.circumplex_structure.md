# Print circumplex-structure test results

Compact display of a
[`fit_structure()`](http://circumplex.jmgirard.com/dev/reference/fit_structure.md)
object: the four factor-analytic criteria with their statistics and
interpretive classifications, and the RANDALL order test with its
randomization p-value.

## Usage

``` r
# S3 method for class 'circumplex_structure'
print(x, digits = 3, ...)
```

## Arguments

- x:

  A `circumplex_structure` object.

- digits:

  The number of decimal places to display (default = 3).

- ...:

  Not used.

## Value

`x`, invisibly.
