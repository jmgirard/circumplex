# Analysis and visualization of circumplex data

circumplex provides functions for analyzing and visualizing circumplex
data.

## Details

Its goal is to unify, modernize, and extend existing methods of working
with circumplex data. Its functions share an underlying design
philosophy and grammar. The three guiding principles it aspires to are:

- **Accessibility:** zero cost, open source, libre; works on many
  platforms; easy to use across skill levels

- **Flexibility:** customizable by the user; extendable for other uses;
  plays nicely with other packages

- **Consistency:** unit-tested quality control; firm naming conventions;
  data flows between functions

To learn more about circumplex, start with the vignettes:
`browseVignettes(package = "circumplex")`
