# Summarize circumplex axes-reliability results

Fuller display of an
[`axes_reliability()`](http://circumplex.jmgirard.com/reference/axes_reliability.md)
object: everything [`print()`](https://rdrr.io/r/base/print.html) shows
plus the estimated variance components (with standard errors) and the
global fit indices.

## Usage

``` r
# S3 method for class 'circumplex_axes_reliability'
summary(object, digits = 3, ...)
```

## Arguments

- object:

  A `circumplex_axes_reliability` object.

- digits:

  The number of decimal places to display (default = 3).

- ...:

  Not used.

## Value

`object`, invisibly.
