# Print circumplex axes-reliability results

Compact display of an
[`axes_reliability()`](http://circumplex.jmgirard.com/reference/axes_reliability.md)
object: the per-axis reliability, SEm, and Nunnally-Bernstein
comparison, with the correlation-as-covariance standard-error caveat.

## Usage

``` r
# S3 method for class 'circumplex_axes_reliability'
print(x, digits = 3, ...)
```

## Arguments

- x:

  A `circumplex_axes_reliability` object.

- digits:

  The number of decimal places to display (default = 3).

- ...:

  Not used.

## Value

`x`, invisibly.
