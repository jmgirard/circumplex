- 2026-07-17/18 (M27, M33): **unwrapping `ssm_draws()` displacement intervals.** Non-contrast rows wrap each CI endpoint independently into [0, 360) (only the contrast row is realigned onto the estimate's branch), so a seam-straddling interval has `d_lci > d_uci`. - 2026-08-23 (M106): **a diagnostic must not read an eigenvector where the defect it diagnoses creates multiplicity** — k duplicate item pairs give a k-dimensional near-null space and LAPACK returns an arbitrary basis of it, so relabelling one matrix moved the message between naming an arbitrary member pair and naming nothing; derive the diagnostic from the refusal CRITERION instead (here, the correlation that forces the floor by Cauchy interlacing on its own account), which is basis-free by construction and replaces hand-set cutoffs with one read off the criterion.
- 2026-08-23 (M106): **a `pgrep -f` wait loop matches its own wrapper shell** — an `until ! pgrep -f 'devtools::test()'` backgrounded here never exits, because the waiting shell's command line contains the literal it greps for, so the condition is true forever and the loop spins until the session ends. - 2026-08-24 (M108): **a precondition gating a frozen comparison can swallow the very regression it guards.** `skip()` is green to testthat and to `R CMD check`, so a gate reading "this machine does not reproduce the committed values" also absorbs a REFUSAL from the code under test, and a run where every case skipped is indistinguishable from one where every case passed — M108 shipped such a gate and its own review found all six cases skipping on ubuntu and windows, silently. Three rules: keep one machine-independent assertion (a geometry fingerprint) OUTSIDE every such gate, discriminate a refusal from a non-reproduction, and assert the domain is non-empty. The gate is needed because a frozen relative error is platform-specific in BOTH halves — the matrix built through `cos()` and the shipped BLAS pricing — but that is a reason to bound it, not to trust it.
