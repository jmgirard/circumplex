# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas. Not status, not decisions. One line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. A line may instead be a pointer to a doctrine module a matured family graduated into; it carries no date or milestone tag. Caps: line count (prune/retire) and bytes (compress). - 2026-07-18 (M32/M35; extended M71, M84): **`is.na()` does not reject `±Inf` — guard user-facing numerics with `!is.finite()`.** Recurs a layer down (`ssm_has_location()`); at the matrix level `any(diag(sigma) <= 0)` misses `+Inf` and `cov2cor()` LAUNDERS an infinite variance into a zeroed row with unit diagonal — a diagonal guard needs its own `is.infinite()` arm, FALSE on `NA`/`NaN` so no missing-value route moves (M71); `nzchar(NA_character_)` is TRUE and `x[[NA_character_]]` returns NULL — name validity is `all(!is.na(nms) & nzchar(nms))` (M84). - 2026-07-17/18 (M27, M33): **unwrapping `ssm_draws()` displacement intervals.** Non-contrast rows wrap each CI endpoint independently into [0, 360) (only the contrast row is realigned onto the estimate's branch), so a seam-straddling interval has `d_lci > d_uci`. - 2026-08-24→ 2026-08-30 (M108 family, resolved M115): **a precondition gating a frozen comparison can swallow the regression it guards; the fix is to stop freezing a measurement.** `skip()` is green to testthat and `R CMD check`, so a gate reading "this machine does not reproduce the committed values" also absorbs a REFUSAL from the code under test, and an all-skip run looks like an all-pass one — M108 shipped such a gate and all six cases skipped silently on ubuntu and windows; M111 and M113 hit both directions of the same trap. Root cause: committing a MEASUREMENT — one machine's error is no yardstick for another, so it needs a gate, and the gate goes vacuous. M115 commits the EXACT quantity instead (hi/lo pairs from the exact-rational oracle), so each machine measures its own error and nothing needs gating. Where a frozen measurement is unavoidable: keep one machine-independent assertion OUTSIDE the gate, discriminate a refusal from a non-reproduction, assert the domain is non-empty, and fence the ROUTE a derived figure took, not its digits. M115's own repair reintroduced the defect at a fresh site, so sweep adjacent sites.
- 2026-08-31 (M116): **prove a replacement check against what REMAINS asserted; plant the defect in the code under test, not in the test's yardstick copy.** Brackets fed an error retained identities pinned to zero reduced to those identities' predicate; a yardstick-shift plant proves the mechanism, not the coverage.
- 2026-08-30 (M112): the review consistency gate runs `devtools::build_readme()`, and the README plot re-renders non-deterministically — a `git add -A` in the same pass commits a PNG the milestone never touched. - 2026-09-02 (M120): **a byte-exact guard over generated output cannot pass where the output is not reproducible, and a digit mask leaves its padding behind.** Pre-computed vignettes need a staleness guard, but an ill-conditioned fit's printed numbers move across BLAS implementations — declare an explicit masked region naming its reason, hold everything else byte-exact, and collapse blank runs alongside the digits, because `print()` right-aligns a column to its widest entry so a shorter count shifts the whole column. Regions are CHUNK-granular, so masking one warning masks that chunk's other constants — isolate the volatile call if the rest must stay pinned. Separately: in testthat 3e `tolerance` is RELATIVE — `tolerance = 5` passes a 10x difference and `1e-1` near 350° admits ±35°; assert `abs(est - truth) < bound` in the unit you mean. `on.exit()` at `Rscript` top level never fires.
