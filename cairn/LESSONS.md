- **Matured verification craft lives in `cairn/test-craft.md`** (graduated by M104). Read it when the scope touches tests, guards, tolerances, fixtures or CI.
- 2026-07-19 (M7 family; extended M31, M119, M120, M164, used M178): **a step that doesn't run reports success.** `devtools::check()` sets `NOT_CRAN=true`, so on-CRAN skips show only in `R CMD check --as-cran` on a tarball (M119). vdiffr skips in bare Rscript (M31). Source-tree reads skip in `R CMD check`; use `system.file()` (M109). `R CMD check` exits 0 on WARNINGs: read `00check.log` (M121). `knitr::knit()` defaults to `error = TRUE` (M164).
- 2026-08-16 (M90, used M170): **a number is "measured" only when computed from the committed construction itself, in the metric being claimed**: rebuild an anchor from the committed fixture first. An oracle figure is the oracle's path, not the shipped one: M161 drew through `draws =`, skipping `ssm_trajectory()`'s `vcov` checks, and scored a non-PD fit as a miss. Before docs quote such a figure, name the path and basis it measured (M163).
- 2026-08-24→2026-09-05 (M108 family; M115, M122, used M178): **a precondition gating a frozen comparison swallows the regression it guards.** `skip()` is green, so a gate reading "this machine does not reproduce the committed values" absorbs a REFUSAL by the code under test. Commit the EXACT quantity so each machine measures its error (M115); keep one machine-independent assertion outside it. A refusal is a platform fact too (M122, D-055).
- 2026-08-31 (M116, used M171): **prove a replacement check against what REMAINS asserted; plant the defect in the code under test, not in the test's yardstick copy.** Brackets fed an error retained identities pinned to zero reduced to those identities' predicate; a yardstick-shift plant proves the mechanism, not the coverage.
- 2026-09-25 (M156): `pkgdown::build_article()` writes the page but never refreshes `docs/deps`, so after a theme change a locally served page pairs new HTML with the old stylesheet (dark navbar, no dark-mode code rules): run `pkgdown::init_site()` first.
- 2026-10-17 (M157): `as.data.frame()` on a matrix keeps duplicate column names but renames a blank one to `V<n>`, which can collide with a real name, so judge names after conversion. `factor()` matches doubles by `as.character()`, 15 significant digits for most doubles (a large whole number keeps more; corrected M158), while `print()` shows 7, so "ids that print alike" is the wrong rule for when ids merge.
- 2026-10-18 (M159): a POSIXlt is a list, so `is.list()` alone refuses a date-time column; `$<-` keeps POSIXlt in a data frame, but arithmetic on a POSIXlt returns POSIXct, so build a fixture with `as.POSIXlt()` after the arithmetic. `format()` rounds to 7 significant digits, so a message quoting an offending value can contradict its own refusal (0.99999999 prints as 1): use `digits = 15`.
- 2026-10-18 (M160): two selection idioms empty or mislead without a sign. `seq_len(n)[x]` with character `x` returns all `NA`, so a "positions to names" step written for numbers silently checks nothing for names (resolve names as names). A factor reaches the numeric branch of a selection check by its integer codes, which follow its sorted levels, so it names the wrong column: convert factors with `as.character()` before judging them.
- 2026-10-18 (M159): `[.data.frame` renames a second selected column that shares a name (`PA.1`), while a matrix keeps both names, so a claim that same-named columns "collapse" downstream needs a probe on both shapes before it is acted on; a reviewer's code-reading claim of this kind was false in 10 of 11 exports.
- 2026-10-26 (M167, used M171): a profile-likelihood interval needs F-hat and every profile point at their global minima. `cpm_fit()`'s theory-centred starts miss lower basins, mostly at the Heywood wall at N <= 500 (D-071; corrected M169), so a profile built from them gives endpoints that are too narrow; two starts per evaluation missed them, and an independent endpoint check from dispersed starts and wall probes is what showed it.
- 2026-10-26 (M167, used M170): when a method fails review twice by the same shape, fix a stop rule with numeric gates before writing the next fix (M167-D7). The gates then decide in one run whether the method stays, and a failing method leaves the verdict reported as not established, where a further fix would have bought another return.
- 2026-10-27 (M169, used M171): a CPM doc claim that a lower discrepancy means a smaller p-value or worse RMSEA and CFI holds only at equal df, because `cpm_polish_beta()` can report a reduced model with more df; write "at the same degrees of freedom". A criterion that bars figures on a page also catches code thresholds quoted there, so describe such a mechanism in words.
- 2026-10-28 (M170, used M171): build a CPM refit start from the engine's own parameter vector, clipped, never from `qlogis()` of a reported communality: `cpm_engine()` can push a logit past 37, where `plogis()` gives exactly 1 and `qlogis()` gives Inf. Every start built that way was infinite, and `nlminb()` returned without an error far above F-hat, so the probe silently did nothing on the fits it was for (RR28). Assert that starts are finite.
- 2026-10-28 (M170): store a simulation's raw per-replicate quantities (errors, SEs, F values) and compute every metric from them in the summary, never from a flag derived at run time. M170's coverage rule was wrong in the full run; recomputing from the stored errors and SEs fixed it without a 39-minute re-run, while the stored derived `covered` field stayed wrong.
- 2026-10-28 (M171): two traps before a clean check. The Edit tool writes a typed backslash-u escape as the character itself, and `R CMD check` WARNs on non-ASCII in R code, so write such escapes with a byte-level edit and confirm with `tools::showNonASCIIfile()`. `is_flag(NA)` is TRUE (logical, length 1), so an argument that must refuse `NA` needs `isTRUE(x) || isFALSE(x)`.
- 2026-10-28 (M171, used M178): under `devtools::load_all()` a script calls the copy in the attached `package:` environment, so a plant written only into the namespace never runs; assign it in both and see one comparison fail before trusting a clean run. A top-level `local_mocked_bindings()` lasts the whole test file; save `real <- f` before it to restore `f` in one test.
- 2026-10-28 (M173): testthat 3.1.7 does not build on R 4.5 and later: `reassign.c` calls `SET_BODY` and its siblings, gone from R's API, and vendored Catch needs `std::uncaught_exception`. To test that floor, build a scratch copy with `-D_LIBCPP_ENABLE_CXX20_REMOVED_UNCAUGHT_EXCEPTION` and `reassign_function` stubbed to `Rf_error()`, after a grep shows the suite never calls `with_mock()`.
- 2026-10-28 (M173, used M174): cutting NEWS to a third lost a scope, default or condition in many bullets, and each fresh review pass found a new set. Restate each bullet's conditions from the code while cutting, and bind criteria to scripts (token sets, line counts), not a hand ledger, which failed review three times. `strwrap()` splits backtick spans across lines, so protect their spaces before wrapping.
- 2026-10-28 (M172): two comparison traps. `identical()` of two `cpm_fit()` results is FALSE even for one saved fit read twice, because `corfun` is a closure; compare with `ignore.environment = TRUE`. A scale-relative test `g <= 1e-6 * max(1, abs(F))` accepts `g = F = Inf` and gives `NA` on NaN, so put `is.finite()` on both sides before it.
- 2026-10-28 (M174): `Rscript` here runs in the `en_US` locale, not UTF-8, and some `R/` files have CRLF endings, so `parse(text = )` on `system2("git", c("show", ...), stdout = TRUE)` fails with "unexpected invalid token" until each line is marked `Encoding(x) <- "UTF-8"` and loses its trailing carriage return (`readLines()` drops it itself). `paste0()` of two empty vectors gives ".", so guard names built from parts that can be empty.
- 2026-10-29 (M175, used M176): read a CRAN NOTE's trigger in R's check code before planning against it. The incoming size NOTE fires above `_R_CHECK_CRAN_INCOMING_TARBALL_THRESHOLD_` (default 1e7 bytes), not at the policy's 5 MB. The example-timing NOTE reads only the first examples pass: the `--run-donttest` pass runs with `do_diff = FALSE`, so `\donttest{}` takes an example out of CRAN's timing.
- 2026-10-29 (M175, used M177): when a knit fails, `knitr::knit()` writes the output made so far to its output file (corrected M177), so a precompute that writes the shipped `.Rmd` in place leaves it cut short when a device package such as `svglite` is missing. Check `requireNamespace()` before knitting, and probe with a library of symlinks to every package but the hidden one, with a control showing the others still load.
- 2026-10-29 (M175, used M176): two figure-format traps. `magick::image_quantize()` in its default colorspace darkened light-grey fills (RMSE up to 0.093), where `colorspace = "sRGB"` gave at most 0.0021. svglite writes plotmath symbols such as Δ in `font-family: "Symbol"`, which Windows encodes without them; `dev.args = list(system_fonts = list(symbol = "Arial"))` draws them in Arial.
- 2026-10-29 (M176): two inline-SVG traps. A `var()` inside an SVG presentation attribute is not honored by every viewer, so theme colors go in CSS rules on classes, with literal colors left in the attributes. A marker's default `markerUnits="strokeWidth"` scales an arrowhead by the stroke width (7 × 2.5 = 17.5 px), so a short arrow's head overshoots its base: use `userSpaceOnUse`, and drop the head when the line is shorter.
- 2026-10-30 (M178): read where `skip_on_cran()` blocks run from a CI log's SKIP count, not from the workflow file: `r-lib/actions/setup-r@v2` exports `NOT_CRAN=true`, so every job using it runs them (SKIP 104 against 523 skip sites), and M168 wrote the opposite from the YAML. A CRAN-live test must not assert that `atan2(-y, -x) - atan2(y, x)` is exactly pi, since that rests on the platform's libm.
