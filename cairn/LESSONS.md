# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas. Not status, not decisions. One line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. Caps: line count (prune/retire) and bytes (compress). Git holds the case histories (milestone tags).

- 2026-07-12→2026-08-18 (M13 family): **a guard has teeth only if you break the guarded line and see it fail — prove by mutation, never by eye.** test re-types the production expression (M13); assertion implied by the defect (M33); fixture sits where the bug is invisible (M35) or is impossible — build from ONE population, assert estimates near truth (M61); guard never matched (M40); probe narrower than what it probes — scope it, `grep -F` metacharacters, verify ranges by first AND last line, flatten wrapped prose (M43, M57); guard checks fewer dimensions than the indexing; mutation reddens for the wrong reason — assert the quantity the path determines (M59); seam mock routes past the condition — assert it unmocked (M62); two sides built by the SAME line catch nothing common-mode — pin one to a literal (M65); a mutation certifies only the REVERT — pin verb stems, pair negatives with positives, never author-certify (M66); sides sharing an ORIGIN cannot disagree — name each's independent origin (M72); `pdftotext` proves in-FILE, not on-PAGE — render and look; after correcting an anchored fact, `grep -rn` the OLD string repo-wide (M73); a suite that never visits the threshold kills no mutants — pin 1.05×/0.95× the floor, verify reddening (M89); vdiffr baselines count only on the CHANGED path (M38); a block-EXTRACTION helper certifies content, never PLACEMENT — pin the container header and seam bytes too (M94).
- 2026-08-14→2026-08-17 (M82 family): **the mutation harness itself lies.** `git checkout --` restores from the INDEX, discarding uncommitted work — commit before mutating, restore by copy, re-hash after every restore (M82, M92); `gregexpr` returns −1 with length 1 — assert the ARTIFACT changed (blob hash), never that the edit call returned (M82); `on.exit` restores don't survive a hard kill — one mutant per invocation, mutate only committed files (M88); a DOTALL regex spans ACROSS call sites — anchor multi-line edits line-by-line, re-read aimed sites before recording success (M87); a top-level mutant in a `sys.source()`d script executes at load — plant inside a function never called (M87).
- 2026-07-16→2026-08-16 (M21 family): **anything run outside `devtools::load_all()` reads the INSTALLED package** — introspect under `load_all()`, print `packageVersion()` (M21, M34); a `data-raw/` script verifies the ARTIFACT — `load()` `data/*.rda` directly (M78); a `parallel = "snow"` worker reads the installed package — `devtools::install()` first (M81); a red local check with the `ld: emutls_w` gfortran signature is an environment fact, not a branch defect (`R_MAKEVARS_USER` with `FLIBS=`; M81/M82); `document()` rewrites `Config/roxygen2/version` to the machine's roxygen2 — revert, don't sweep into a branch (M85); a measurement run is not an authoring run — check `git status` after any read-only run, restore stamp-only diffs (M86); covr installs WITHOUT vignettes — vignette-reading tests must skip there (M92); ubuntu-latest 24.04 ships no R — `Rscript` needs `setup-r`, and only a LIVE run shows it (M93).
- 2026-07-16 (M23, M63): **a spec's quantitative claims and the CONDITIONS they rest on need the adversarial-derivation treatment code gets.** "Paired CIs are narrower at ρ>0" was false past |Δd|=90° and survived drafting; write efficiency/coverage claims as conditionals with the condition derived, and give the oracle a cell EXPECTING the reversal (M23). A rule generalized from two measured layouts was disproved by a third (antipodal blocks bias ξ1 −9%), and a worked example inherited its fixture's parameters — a test fencing instances does not fence the condition (M63).
- 2026-07-16 (M25): an "independence baseline" for a MEAN-BASED estimator cannot be built by permuting rows within the drawn sample — group means are permutation-invariant. Draw the comparison arm from FRESH units; a reversal-expecting oracle cell exposed it.
- 2026-07-16 (M25): never resolve numeric column indices to names before subsetting a data.frame — `[.data.frame` resolves duplicated names to the FIRST match, so cbind-ed same-named blocks silently collapse onto block 1. Subset by position and guard cross-block selections with an overlapping-columns error; drop info columns by name, not position.
- 2026-07-16 (M26): kernel bit-parity: R's `%%` is not C++ `modu()` at the pole (a tiny-negative angle goes to 0, not 2π) — wrap atan2 output with `d + 2*pi*(d < 0)`; and bit-exact oracle comparisons must take both sides from one conversion expression or they fail by 1 ulp.
- 2026-07-17 (M28): collapsing a per-row long column by first *physical* row discards a validated value when that row is NA — take the first *non-NA* value per person, indexing the original column to preserve type; pair any reshape oracle with a "blank the first-occasion value, assert unchanged" regression.
- 2026-07-17 (M29): seed EVERY stochastic call in a diagnostic test — including the `ssm_analyze()` that builds the object — and prove determinism under varied incoming RNG. To validate a plug-in coverage diagnostic, compare its reported coverage to a direct Monte-Carlo of the REAL shipped procedure at the SAME plug-in; only an engine re-deriving the replay independently is a strong check.
- 2026-07-18 (M31, M32): subclass `CoordRadial` by copying a stock `coord_radial(...)`'s computed fields into `ggproto(NULL, CoordCircumplex, ...)`; verify by transforming known points. Pin the angular range COORD-SIDE (`thetalim=c(0,360)`, `expand=FALSE`), NEVER via `scale_x_continuous(limits=)`, which censors a seam-straddling arc's `xmax>360` to NA; an empty canvas needs `geom_blank()`; move the radial axis via `self$r_axis_inside` in `setup_panel_params` before delegating.
- 2026-07-18 (M31): in a bare `Rscript`/`test_dir` env vdiffr auto-SKIPS, so plot changes look green while stale baselines go unchecked — regenerate by deleting `_snaps/<file>/*.svg` under `NOT_CRAN=true`.
- 2026-07-18 (M31): after a coord rewrite the canvas furniture is the coord's panel grid — locate layers by geom class, read spoke labels from the x-scale, and assert behavioral criteria at grob level; a passing vdiffr baseline is NOT a fencing test.
- 2026-07-18 (M32/M35; extended M71, M84): **`is.na()` does not reject `±Inf` — guard user-facing numerics with `!is.finite()`.** Recurs a layer down (`ssm_has_location()`); at the matrix level `any(diag(sigma) <= 0)` misses `+Inf` and `cov2cor()` LAUNDERS an infinite variance into a zeroed row with unit diagonal — a diagonal guard needs its own `is.infinite()` arm, FALSE on `NA`/`NaN` so no missing-value route moves (M71); `nzchar(NA_character_)` is TRUE and `x[[NA_character_]]` returns NULL — name validity is `all(!is.na(nms) & nzchar(nms))` (M84). One shape: the predicate is FALSE on the value you meant to reject, and the next operation swallows it.
- 2026-07-17/18 (M27, M33): **unwrapping `ssm_draws()` displacement intervals.** Non-contrast rows wrap each CI endpoint independently into [0, 360) (only the contrast row is realigned onto the estimate's branch), so a seam-straddling interval has `d_lci > d_uci`. Where the estimate is within a half-turn of BOTH bounds, shift each endpoint by its signed circular distance `((bound - est + 180) %% 360) - 180` — never by the estimate's branch offset. That clamp cannot represent an arc over 180°; for arbitrary non-contrast intervals anchor the lower bound: `lo <- branch - ((est - lci) %% 360); hi <- lo + ssm_arc_span(lci, uci)`. `check()` catches neither; the figure just renders wrong.
- 2026-07-18 (M33): `results$Occasion` is CHARACTER and `details$occasions` is the only ordering authority — a discrete ggplot2 scale re-sorts alphabetically, flipping `T10`/`T2`; factor against `details$occasions` in any occasions plot.
- 2026-07-18 (M33): rendering a new plot and LOOKING at it catches what no data-level test does. Budget one render-and-inspect pass per new figure; data fences and vdiffr both pass a figure that reads wrong.
- 2026-07-18 (M35): to extract a shared helper from a prior milestone's code and keep that milestone's suite as an UNTOUCHED fence, parameterize by the varying column's *name* rather than renaming it — zero test edits, and the fence claim stays literal.
- 2026-07-18 (M34): agent-written file content can carry leaked tool-call scaffolding at the tail, and `check()`, `check_pkgdown()` AND CI all pass it (pandoc emits unmatched closing tags as raw HTML). After writing any doc file wholesale, check its tail bytes (`tail -6 f | od -c`).
- 2026-07-18 (M34): `ssm_analyze_long()` derives occasion order from the column TYPE — first-appearance for character, `levels()` for a factor, and `factor()` sorts alphabetically. Never document occasion order as unconditionally temporal without naming the factor branch.
- 2026-07-18 (M36): "it works" is not "it is the mechanism" — a shipped fix explained a component that contributed nothing (ablation left baselines byte-identical). When a fix has two moving parts, ablate each separately before writing the comment.
- 2026-07-18 (M37): a CUSTOM optional aesthetic mapped to a discrete column silently destroys a layer — `add_group()` builds `group` from EVERY discrete column when the caller maps none, so a character `order` aes left `GeomPath` drawing nothing. Prefer `geom_path()` parity; ordering belongs in the wrapper that knows the true order. An arrow terminating AT a point marker draws UNDER it — draw arrowed paths last, head sized to clear.
- 2026-07-19 (M7 family): **a step that doesn't run reports success.** `devtools::check()` defaults `manual = FALSE`, so the PDF-manual step silently skips — grep the log for `checking PDF version of manual ... OK`, never trust `Status: OK`, and `R CMD Rd2pdf` when touching roxygen (M7, M57); deny-by-default on hostile characters, enumerated classes leak (M7). A truncated log view is not a count — grep the WHOLE log, pin `cli.width` first (2026-08-08).

- 2026-07-19 (M40 family; M42/M45/M47/M72): **an `Extraction:` status may claim only what each channel actually saw.** Authoring a source note is a fresh extraction — attestations don't transfer (M40); an OCR text layer is not a second witness — ask what channel reads the ANCHOR: in-figure values are a rasterized read whatever the container, and `pdftotext` twice is one channel (M42-D1, M72); page-range claims overclaim outside anchors — verify value coverage; keep `verified <date>` unbolded, off line-start (M45); copy an existing page's Provenance block, not the template (M47). - 2026-07-24 (M56 family; nine recurrences): **a change making a fact newly true or false strands prose elsewhere — sweep every surface, BOTH directions.** Grep docs for the OLD claim's keywords (M56); a widened definition strands its enumerations — grep every surface ENUMERATING what you extended, pinning completeness not presence (M62, M63); the vignette is the forgotten surface, and an AC enumerating doc surfaces is itself an enumeration (M66); a split claim's introducing sentence is a claim too (M68); fix a defect's siblings — `grep -rn` its shape, not the fix (M69); a record DOCUMENTING a defect goes stale when it's fixed — sweep the `references/` page and INDEX line in the same commit (M74); a new universal claim can CONTRADICT existing records — before "all X are Y", grep help pages and audit records for exceptions (M77); a hand-pinned count of a MOVING artifact cannot stay true — state the derivation, no number (M87).
- 2026-07-25 (M58): **a package removed from a CI dependency allowlist is never EVICTED from the Actions cache** — `setup-r-dependencies` restores the whole library and re-saves it, so "we no longer install X" becomes true only after purging every key sharing the `restore-keys` PREFIX. - 2026-07-25 (M58): `paths-ignore` on a `pull_request` trigger is evaluated against the WHOLE PR diff (only `push` filters read the push's own files), and an ignore list is per-WORKFLOW — `man/**`/`README.md` are inert for `R CMD check` but are pkgdown site INPUTS, so one list copied across workflows would leave the site stale.
- 2026-07-25 (M58): a guard that validates an artifact but not the switch making the artifact authoritative has a hole exactly where regression is likeliest — assert the enabling condition beside the thing it enables, scoped so a legitimate neighbour cannot false-positive.
- 2026-07-26→2026-08-18 (M59 family): **a tolerance calibrated on one machine is not a tolerance — derive the bar from the DISCRIMINATION required, with headroom for platform noise.** covr instrumentation perturbs optimizer results — green check ≠ green coverage job (M59); testthat 3e `tolerance` is RELATIVE — write `expect_lt(abs(x - y), tol)` and pin the measured value, not the rounded quote (M61, M92); prose bounds pinned off one run fail their own re-run — state them comparatively ("under 5% of the estimate's own SE") (M64); a criterion fencing an RB/RR artifact's CONTENT must be satisfiable before it archives (IP4) (M64); a committed fixture from the authoring machine makes bit-exactness locally unfalsifiable — gate exact replay on the environment the fixture RECORDS, keep an ungated loose bar, never environment-gate pure arithmetic over a frozen file (M68) — a committed output SNAPSHOT is the same fixture (CI measured 3rd-decimal platform deltas; M94); too LOOSE fails the other way — check the alternative actually fails at the bar (M69).
- 2026-07-26 (M60 family): **replacing a narrow check with a general one drops what the narrow one refused by ACCIDENT — enumerate the old gate's incidental rejections, re-assert each** (`anyNA()` never rejects `±Inf`) (M60); a clause suppressing a false case suppressed a true one — check which side of the filter the comparand sits on (M67); exempting a syntactic slot fails open where it means something else — enumerate its POSITIONS (M83); an exemption INFERRED from guarded data is evaded by any unenumerated value — declare it as an argument (M86); a REPLACEMENT guard can be WEAKER — `sort()` drops NA names under `na.last = NA`; a regex constant in an anchored pattern must keep its own `(...)` (M98); and what it ignored INERTLY it now ADMITS — a null value an equality passed over trips an exclusion, turning a neighbour load-bearing (M99).

- 2026-08-07 (M75 family): **an expected value derived from the implementation's own expression can never disagree with it.** Sweep the SOURCE's inventory, not consumers' claims (M75); derive expectations from the REQUIREMENT, or extract the shared rule as a function both call and fence ITS contract (M76) — prove callers call it: grep the predicate's BODY, mutate it to a constant (M78); a phrase that can arrive as DATA needs the rendered line asserted with its label prefix (M78); an "accepted, and nothing else" criterion makes the recognizer the set's definition, tested as a PARTITION in both directions (M79); converse: two derivations agreeing on today's data are not one set — a shared NAME is not a shared DEFINITION; extract the base, layer the filters (M83); a message quoting its input satisfies any match on that input — assert phrases only the code COMPOSES (M88).
- 2026-08-16 (M90): **a number is "measured" only when computed from the committed construction itself, in the metric being claimed** — rebuild any anchor from the committed fixture, in every metric the surfaces price, before recording OR dismissing it. - 2026-08-07 (M75): a source's table can sit outside both its subject's chapter and the contents listing (instance and evidence: `references/horowitz2003.md`). Before recording that a source does not publish a value, grep the whole document for the value's shape.
- 2026-08-18 (M94): recasting a deliberately NEGATIVE validation claim ("not validated on X") as a positive scope ("validated on Y only") asserts per-member evidence the record may not hold — state what the STUDY covered, not what each member is.
- 2026-08-18→19 (M95 family): **a check can pass by not checking.** A cancelled run is `completed` without being a verdict, so a gate reading "most recent completed run" false-fails when `cancel-in-progress` kills a job — read the newest run concluding success OR failure; an absent run is no verdict where `paths-ignore` allows none. Three no-ops: macOS has no `timeout`, so `timeout N gh pr checks --watch` fails while a trailing `echo` reports success; YAML 1.1 reads a bare `on:` as TRUE, so `read_yaml(f)[["on"]]` is NULL and a trigger assertion passes vacuously (M95); and zsh never word-splits unquoted `$FILES`, so a multi-file grep reads nothing and passes (M97). A guard proving a NEGATIVE over open-ended grammar loses to the next construct (M96): compare PRODUCED output to a committed expectation, out of band and injectively.
