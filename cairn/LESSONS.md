# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas — captured at milestone end, surfaced at plan time. Not status, not decisions. One line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. Two `cairn_validate` axes: line count (`weight caps`, prune/retire) and per-line length (`record density`, compress). Git holds the record — each milestone tag below names the commit-era case history; this file keeps the operative rules.

- 2026-07-12→2026-08-17 (M13 family): **a guard has teeth only if you break the guarded line and see it fail — prove by mutation, never by eye.** Mechanisms, each tagged for its full case in git: the test re-types the production expression instead of calling the code path (M13); the assertion is arithmetically implied by the defect it should catch (M33); the fixture sits in the regime where the bug is invisible (M35), or is itself impossible — build fixtures from ONE population and assert estimates land near its truth, so fixture validity is under test too (M61); the guard never matched at all (M40); the probe is narrower than what it probes — scope probes to the thing probed, use `grep -F` for regex metacharacters, verify a line range by its first AND last line, flatten wrapped prose before matching (M43, M57); the guard checks fewer dimensions than the indexing uses, a mutation reddens for the wrong reason (assert the quantity the path actually determines), and an absolute bound far from its threshold beats stating nothing comparatively (M59); a seam mock routes past the condition under test — assert the condition against the unmocked path; the mocked test's title claims only wiring (M62); two sides built by the SAME line of code catch nothing common-mode — pin one side to a literal (M65); a mutation certifies only the REVERT — pin verb stems not phrasings, pair every negative assert with a positive, never let the author certify their own guard (M66); two sides sharing an ORIGIN cannot disagree — name each side's independent origin before trusting a clean run (M72); `pdftotext` proves a string is in the FILE, never on the PAGE — render and look; and after correcting any anchored fact, `grep -rn` the OLD string repo-wide (M73); an acceptance suite that never visits the threshold kills no mutants — pin near-threshold points (1.05×/0.95× the floor) and verify each mutant reddens (M89); vdiffr baselines are evidence only after checking they exercise the CHANGED path (M38).
- 2026-08-14→2026-08-17 (M82 family): **the mutation harness itself lies.** `git checkout --` restores from the INDEX and silently discards uncommitted work — commit before mutating, snapshot to scratch, restore by copy, re-hash (`git hash-object`) after every restore (M82, M92); `gregexpr` returns −1 with length 1, so assert the ARTIFACT changed (blob hash), never that the edit call returned (M82); `on.exit`/`atexit` restores do not survive a hard kill — one mutant per invocation, mutate only committed files so HEAD is the restore source (M88); a DOTALL regex spans ACROSS call sites — anchor multi-line edits line-by-line and re-read the aimed sites before writing any record claiming the edit landed (M87); a mutant at TOP LEVEL of a `sys.source()`d script executes at load and reddens everything for the wrong reason — plant inside a function never called (M87).
- 2026-07-16→2026-08-16 (M21 family): **anything run outside `devtools::load_all()` reads the INSTALLED package, not the dev tree** — run introspection under `load_all()` and print `packageVersion()` to prove which tree answered (M21, M34); a `data-raw/` script verifies the shipped ARTIFACT, so read `data/*.rda` with `load()` directly (M78); a `parallel = "snow"` worker is a fresh session reading the installed package — `devtools::install()` before parallel tests (M81); a red local check with the `ld: emutls_w` gfortran signature is an environment fact, never a branch defect (workaround: `R_MAKEVARS_USER` with `FLIBS=`, deliberately uncommitted; M81/M82); `devtools::document()` rewrites `Config/roxygen2/version` to the machine's roxygen2 while `man/`/`NAMESPACE` stay byte-identical — revert it, don't sweep it into a branch (M85); a measurement run is not an authoring run — check `git status` after any script invoked only to read its output, and restore stamp-only diffs (M86); covr installs WITHOUT vignettes, so a test reading a vignette source must skip there — only CI shows it (M92).
- 2026-07-16 (M23, M63): **a spec's quantitative claims and the CONDITIONS they rest on need the adversarial-derivation treatment code gets.** "Paired CIs are narrower at ρ>0" was false past |Δd|=90° and survived drafting; write efficiency/coverage claims as conditionals with the condition derived, and give the oracle a cell EXPECTING the reversal (M23). A rule generalized from two measured layouts was disproved by a third (antipodal blocks bias ξ1 −9%), and a worked example inherited its fixture's parameters — a test fencing instances does not fence the condition (M63).
- 2026-07-16 (M25): an "independence baseline" for a MEAN-BASED estimator cannot be built by permuting rows within the drawn sample — group means are permutation-invariant. Draw the comparison arm from FRESH units; a reversal-expecting oracle cell is what exposed it.
- 2026-07-16 (M25): never resolve numeric column indices to names before subsetting a data.frame — `[.data.frame` resolves duplicated names to the FIRST match, so cbind-ed same-named blocks silently collapse onto block 1. Subset by position and guard cross-block selections with an overlapping-columns error; drop info columns by name, not position.
- 2026-07-16 (M26): kernel bit-parity: R's `%%` is not C++ `modu()` at the pole (a tiny-negative angle goes to 0, not 2π) — wrap atan2 output with `d + 2*pi*(d < 0)`; and bit-exact oracle comparisons must take both sides from one conversion expression or they fail `expect_identical` by 1 ulp.
- 2026-07-17 (M28): collapsing a per-row long column by first *physical* row (`col[match(ids, id)]`) discards a validated value when that row is NA — take the first *non-NA* value per person, indexing the original column to preserve type. Pair any reshape oracle with a "blank the first-occasion value, assert results unchanged" regression.
- 2026-07-17 (M29): seed EVERY stochastic call in a diagnostic test — including the `ssm_analyze()` that builds the object — and prove determinism under varied incoming RNG, not standalone. To validate a plug-in coverage diagnostic, compare its reported coverage to a direct Monte-Carlo of the REAL shipped procedure at the SAME plug-in; an engine re-deriving the replay independently is the strong check, one sharing the replay code validates only wiring.
- 2026-07-17 (M30): a design spec leaning on a dependency's parameters must verify each against the *claimed floor version's* source, not the installed one — pin capability claims to the version you claim, not the one you have.
- 2026-07-18 (M31, M32): subclass `CoordRadial` by copying a stock `coord_radial(...)`'s computed fields into `ggproto(NULL, CoordCircumplex, ...)` and verify by transforming known points. Pin the angular range COORD-SIDE (`thetalim=c(0,360)`, `expand=FALSE`), NEVER via `scale_x_continuous(limits=)`, which censors a seam-straddling arc's unwrapped `xmax>360` to NA; an empty `ggcircumplex()` needs `geom_blank()` to train scales; move the radial axis via `self$r_axis_inside` in `setup_panel_params` BEFORE delegating.
- 2026-07-18 (M31): in a bare `Rscript`/`test_dir` env vdiffr auto-SKIPS (svglite/font mismatch), so plot changes look green while stale baselines go unchecked — regenerate by deleting `_snaps/<file>/*.svg` under `NOT_CRAN=true`. Auto-printing examples create `Rplots.pdf` at the root → add to `.Rbuildignore`.
- 2026-07-18 (M31): after a coord rewrite the canvas furniture is the coord's panel grid — locate layers by geom class, read spoke labels from the x-scale, and assert behavioral criteria at grob level; a passing vdiffr baseline is NOT a fencing test.
- 2026-07-18 (M32/M35; extended M71, M84): **`is.na()` does not reject `±Inf` — guard user-facing numerics with `!is.finite()`.** Recurs a layer down (`ssm_has_location()` is `!is.na()`-based); at the matrix level `any(diag(sigma) <= 0)` misses `+Inf` and `cov2cor()` LAUNDERS an infinite variance into a zeroed row with unit diagonal, so `solve()` succeeds — a diagonal guard needs its own `is.infinite()` arm, which is FALSE on `NA`/`NaN` and so disturbs no missing-value route (M71); and `nzchar(NA_character_)` is TRUE while `x[[NA_character_]]` returns NULL, so name validity needs `all(!is.na(nms) & nzchar(nms))` (M84). One shape: the predicate is FALSE on the very value you meant to reject, and the next operation swallows it silently.
- 2026-07-17/18 (M27, M33): **unwrapping `ssm_draws()` displacement intervals.** Non-contrast rows wrap each CI endpoint independently into [0, 360) (only the contrast row is realigned onto the estimate's branch), so a seam-straddling interval has `d_lci > d_uci`. Where the estimate is within a half-turn of BOTH bounds, shift each endpoint by its signed circular distance `((bound - est + 180) %% 360) - 180` — never by the estimate's branch offset. That clamp cannot represent a stored arc over 180°; for arbitrary non-contrast intervals anchor the lower bound: `lo <- branch - ((est - lci) %% 360); hi <- lo + ssm_arc_span(lci, uci)`. `check()` catches neither; the figure just renders wrong.
- 2026-07-18 (M33): `results$Occasion` is CHARACTER and `details$occasions` is the only ordering authority — a discrete ggplot2 scale re-sorts alphabetically, flipping `T10`/`T2`. Factor against `details$occasions` in any occasions plot. Also: the prior-PR-comments review lens is a permanent clean no-op in this repo (every merged PR has 0 review comments), so its "no findings" carries no evidential weight.
- 2026-07-18 (M33): rendering a new plot and LOOKING at it catches what no data-level test does (hue encoding nothing; an invisible legend key). Budget one render-and-inspect pass per new figure; data-level fences and the vdiffr baseline both pass a figure that reads wrong.
- 2026-07-18 (M35): to extract a shared helper from a prior milestone's code and keep that milestone's suite as an UNTOUCHED fence, parameterize by the varying column's *name* rather than renaming it — zero test edits, and the fence claim stays literal.
- 2026-07-18 (M34): agent-written file content can carry leaked tool-call scaffolding at the tail, and `check()`, `check_pkgdown()` AND CI all pass it (pandoc emits unmatched closing tags as raw HTML). After writing any doc file wholesale, check its tail bytes (`tail -6 f | od -c`).
- 2026-07-18 (M34): `ssm_analyze_long()` derives occasion order from the column TYPE — first-appearance for character, `levels()` for a factor, and `factor()` sorts alphabetically (`T1, T10, T2`). Never document occasion order as unconditionally temporal without naming the factor branch.
- 2026-07-18 (M36): a legend key whose break exists but whose GLYPH is missing is a `show.legend` problem — under the default `NA` a layer claims only breaks its own data contains, so `drop = FALSE` keeps the label with a `zeroGrob` symbol. `show.legend = TRUE` on the existing layer is the whole fix. Test by reading key grobs, counting EVERY `points` grob per key.
- 2026-07-18 (M36): "it works" is not "it is the mechanism" — a shipped fix carried a comment explaining a component that contributed nothing (ablating it left baselines byte-identical). When a fix has two moving parts, ablate each separately before writing the comment.
- 2026-07-18 (M37): a CUSTOM optional aesthetic mapped to a discrete column silently destroys a layer — `add_group()` builds `group` from EVERY discrete column when the caller maps none, so a character `order` aes put each row in its own group and `GeomPath` drew nothing. Prefer `geom_path()` parity; ordering belongs in the wrapper that knows the true order. And an arrow terminating AT a point marker is drawn UNDER it — draw arrowed paths last, head sized to clear the marker.
- 2026-07-18 (M38): patching a `ViewScale`'s `breaks` after the coord builds it desynchronizes anything the scale pairs positionally with its own breaks (explicit `labels` abort; index-blanking fabricates literal `NA` labels). Ask the scale to label only its own breaks and add the appended entry separately.
- 2026-07-18 (M38): calibrating a label-collision rule from break spacing calibrates the wrong quantity — collisions track rendered label *width*. Render the candidates before writing the rule.
- 2026-07-19 (M7 family): **a step that doesn't run reports success.** `devtools::check()` defaults to `manual = FALSE` (and `--no-manual` is the repo habit), so the PDF-manual step silently skips — grep the log for `checking PDF version of manual ... OK`, never read `Status: OK` as coverage, and run `R CMD Rd2pdf` when touching roxygen (M7, M57); deny-by-default on hostile characters, enumerated classes leak (M7). A test reading the source tree via `test_path("..","..",...)` dies or skips under `R CMD check` — read the INSTALLED counterpart (`tools::Rd_db()` for Rd, `system.file("doc", ...)` for vignettes); `skip_if_not(file.exists(...))` that always skips on CI is the same trap one step later — split the test so a runtime half still runs on CRAN (M69, M70). `check()` builds from the WORKING TREE, not HEAD — verify `git status` clean before reporting any gate (PR #103). A truncated log view is not a count — grep the WHOLE log for the thing counted, and pin `cli.width` before grepping cli output (2026-08-08).
- 2026-07-19 (M39): ggplot2's radial-axis labels carry per-label `rot` and a sibling `rectGrob` has none — give each backdrop its own `viewport(angle = rot)`. Measure text-with-possible-expressions via `grobWidth` on a `textGrob`, never `stringWidth(as.character(...))` (measures deparsed source). Match a target grob by BOTH structural position AND content — content alone selects the wrong axis, and the theta guide is traversed first. The structural fence passed the broken version; only rendering caught it.
- 2026-07-19 (M40 family; M42/M45/M47/M72): **an `Extraction:` status may claim only what each channel actually saw.** Authoring a source note is itself a fresh extraction — a prior attestation does not transfer (M40); an OCR text layer is not a second witness, and the question is what channel reads the ANCHOR — values printed inside a figure are a rasterized read whatever `pdfinfo` says about the container, and `pdftotext` twice is one channel read twice (M42-D1, M72); a page-range claim overclaims any anchor outside it — verify value coverage, not headline coverage, and keep `verified <date>` unbolded and off line-start or the staleness parser truncates (M45); copy an existing page's Provenance block rather than filling the template — fresh pages drop the caveat and the one-physical-line rule (M47). The gitignored shelf is LIVE: re-check absence claims at merge, not at write.
- 2026-07-19 (M41): a source note's "nothing in the repo uses this" claim must be grepped for the source's FORMULAS, not its citation — an unattributed implementation is invisible to the citation grep. Cross-reference only pages on disk.
- 2026-07-21 (M50): knitr chunks share one environment, so hiding a setup chunk (`echo = FALSE`) leaves later echoed chunks running but no longer self-contained for a reader who copies them. After hiding any setup chunk, grep the echoed chunks for every name it defined.
- 2026-07-21 (M49): a source quote can be verbatim-faithful yet miscategorized by its framing — check a cited claim against the document's OWN taxonomy and the source's sentence-level scope, not just quote fidelity.
- 2026-07-24 (M56 family; nine recurrences): **a change that makes a fact newly true or false strands prose elsewhere — sweep every surface, in BOTH directions.** Grep the docs for the OLD claim's keywords (M56); widening a definition strands its enumerations — grep every surface that ENUMERATES what you extended, and pin completeness (slice the enumeration, assert the new member inside it), not just presence (M62, M63); the vignette is the surface the sweep keeps forgetting, and an AC that enumerates doc surfaces is itself an enumeration needing extension (M66); when you split a claim by condition, the sentence INTRODUCING the split is a claim too (M68); fix a defect's siblings, not one instance — `grep -rn` for the defect's own shape, not the fix (M69); the record that DOCUMENTS a defect goes stale the moment the defect is fixed — sweep the `references/` page and its INDEX line in the same commit as the data fix (M74); a newly written universal claim can CONTRADICT records already there — before writing "all X are Y" about shipped data, grep the package's own help pages and audit records for the exceptions they already document (M77); a hand-pinned count of a MOVING artifact cannot stay true — state the derivation (`git diff --numstat` over the merge) and no number (M87).
- 2026-07-25 (M58): **a package removed from a CI dependency allowlist is never EVICTED from the Actions cache** — `setup-r-dependencies` restores the whole library and re-saves it, so "we no longer install X" becomes true only after purging every key sharing the `restore-keys` PREFIX. Verify by grepping the job's session-info for X, never its lockfile.
- 2026-07-25 (M58): `paths-ignore` on a `pull_request` trigger is evaluated against the WHOLE PR diff (only `push` filters read the push's own files), and an ignore list is per-WORKFLOW — `man/**`/`README.md` are inert for `R CMD check` but are pkgdown site INPUTS, so one list copied across workflows would leave the site stale.
- 2026-07-25 (M58): a guard that validates an artifact but not the switch making the artifact authoritative has a hole exactly where regression is likeliest — assert the enabling condition beside the thing it enables, scoped so a legitimate neighbour cannot false-positive.
- 2026-07-26 (M59 family): **a numeric tolerance calibrated on one machine is not a tolerance — derive the bar from the DISCRIMINATION required, with orders of magnitude left for platform noise.** covr instrumentation perturbs optimizer results, so a green `R CMD check` is not evidence the coverage job passes (M59); testthat 3e `tolerance` is RELATIVE — state absolute bounds as `expect_lt(abs(x - y), tol)` and pin the measured value, not the rounded quote (M61, M92); prose records need the same discipline — a bound pinned off one run fails its own re-run; state it comparatively, e.g. "under 5% of the estimate's own SE" (M64); a criterion fencing an RB/RR artifact's CONTENT must be satisfiable before the artifact archives, since `reviews/archive/` is IP4 history (M64); a committed fixture generated on the authoring machine makes bit-exactness locally unfalsifiable — gate exact replay on the environment the fixture RECORDS, keep an ungated loose bar, and never environment-gate an arm that is pure arithmetic over a frozen file (M68); the opposite failure is a bar too LOOSE to tell the hypothesis from its alternative — check the alternative actually fails at it (M69).
- 2026-07-26 (M60 family): **replacing a narrow validity check with a general one silently drops whatever the narrow one refused by ACCIDENT — enumerate the old gate's incidental rejections and re-assert each** (a non-finite angle was refused only via a length mismatch; `anyNA()` never rejects `±Inf`, third recurrence) (M60). A clause ADDED to suppress a false case suppressed a true one — check which side of the filter the comparand sits on; the fix was `n_used + n_dropped` (M67); exempting a syntactic slot fails open where the slot means something else — enumerate the POSITIONS the exempted construct can occupy (`opts$abort("boom")` names a callee in head position) (M83); an exemption INFERRED from the data under guard is evaded by any unenumerated value — make it a caller-declared argument (`fixture_world = FALSE`), never inferred from the values being guarded (M86).
- 2026-07-26 (M60): a mutation perturbing a quantity the model is provably invariant to CANNOT redden — before treating a green mutation as a coverage hole, ask whether the estimator is identified in that direction, and record the null result. And assert R semantics by running them, not from memory (`split()` coerces numeric groups with `factor()`, whose levels sort numerically).
- 2026-07-27 (M65 family): **a Suggests dependency's API, output order, and message text are all version- and environment-specific.** Feature-detect at RUN time off the dependency's own options, never build time — lavaan renamed the EM cap at 0.7-1 and ABORTS on the old spelling; verify by installing the tarball into a scratch lib and re-running the suite against the other version (M65). lavaan REORDERS the model's variables — realign any lavaan matrix off its own dimnames before use, refuse one carrying none (M66). lavaan wraps messages at emission-time width — make every inter-word gap whitespace-tolerant and test by enumerating the break positions, a finite domain (M67). An unexported function's argument names are not a contract and an existence probe does not test them — probe the CALL, and keep the load-bearing assertion independent of the internal (M68). The saturated-EM's SQUAREM acceleration (0.7 default) is platform-sensitive on thin coverage — the package pins `acceleration = "none"`, the regime its cap was calibrated in (hotfix PR #121, 2026-08-17).
- 2026-08-07 (M75 family): **an expected value derived from the implementation's own expression can never disagree with it.** Sweep the SOURCE's inventory, not the consumers' claims — a record no consumer selected is never counted (M75); derive expectations from the REQUIREMENT, or extract the shared rule as a function both call and fence THAT function's contract (M76) — and prove callers call it: grep for the predicate's BODY, not its name, and mutate it to a constant to watch the test redden (M78); when the phrase under test can also arrive as DATA, assert the rendered line including its label prefix (M78); an "accepted, and nothing else" criterion needs the recognizer to BE the set's definition, tested as a PARTITION in both directions, never by sampled examples (M79); the converse — before collapsing "two derivations of one set" into one, check they are the same set: a shared NAME is not a shared DEFINITION; where they share a base, extract the base and layer each filter (M83); an error message that quotes its own input satisfies any match on that input — assert phrases only the code COMPOSES (M88).
- 2026-08-16 (M90): **a number is "measured" only when computed from the committed construction itself, in the metric being claimed** — rebuild any anchor from the committed fixture, in every metric the surfaces price, before recording OR dismissing it. And when a milestone renames a literal, grep its committed scripts and detectors for the old literal, not only its docs.
