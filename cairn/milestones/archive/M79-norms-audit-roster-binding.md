# M79: Bind the norms audit's batch to the shipped roster

**Status:** done (2026-08-09, PR #107 https://github.com/jmgirard/circumplex/pull/107)

**Goal:** Make `data-raw/audit-norms.R` unable to report a clean run over shipped norm data it never read.

**Outcome:** `audit_norms()` gained a `roster` argument, defaulting to `shipped_roster()` — the `data()`-plus-`circumplex_instrument` sweep crossed with each object's `Norms[[1]]$Sample`, 24 pairs over 15 instruments — and emits a `shipped-sample-not-audited` coverage row (`exempt = FALSE`) for every pair `AUDIT_BATCH` omits. The roster is never derived from `objects`, which stays a per-instrument value override: a `csie`-only batch reports 23 gaps whether or not `csie`'s own object is injected, where it reported 0 before. Dropping any one of the 24 batch rows now aborts or gaps, 6/18/0, against 6/8/10 before. Marker recognition became definitional — `MARKER_BEGIN`/`MARKER_END` compared byte-for-byte plus one anchored `MARKER_TAGGED` regex, nothing trimmed — so the three accepted shapes are readable off the constants and thirteen near-misses abort by name; one `source_note_markers()` serves both `parse_source_note()` and `source_note_block_tags()`, replacing a markdown fence tracker whose unclosed-fence case silently hid every later block. An untagged block read by two instruments is refused, naming both and the citekey. `instrument_names()` and `instrument_object()` moved into `R/instrument_oop.R` so the audit, `instruments()` and `helper-norms.R` share one enumeration, with `instruments()` byte-identical.

**Decisions:** none milestone-local. Nothing in `data/` moved and no D-entry was touched; IP5 is served, not changed.
