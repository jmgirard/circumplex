# M176: Replace the introduction GIFs with a slider applet

**Status:** done (2026-10-29, PR #210 https://github.com/jmgirard/circumplex/pull/210)

**Goal:** One interactive figure, in which the reader moves sliders for elevation, amplitude and displacement, replaces the three animated GIFs in the introduction vignette.

**Outcome:** `vignettes/VIG1-{e,a,d}.gif` (1,023,015 bytes, 2018, no source) are deleted. `vignettes/ssm-curve-applet.js` draws an SVG plot of e + a·cos(θ − d). It has sliders for e (−0.5 to 0.5), a (0 to 0.5) and d (5 to 360, the pole labelled 360 per D-003), readouts, a reset button, a dashed e line, an a arrow, a d triangle and points at the eight octants. When a = 0, d reads "undefined". Colors are CSS rules that follow pkgdown's `data-bs-theme`, with literal fallbacks in the SVG attributes. Sliders carry `aria-valuetext`. A `results = "asis"` chunk in `introduction-to-ssm-analysis.Rmd.orig` writes the source inline. A `<noscript>` svglite figure is the no-JavaScript fallback. `tools/check-ssm-applet.mjs` checks the curve, peaks, octants, path, linear axes, slider ranges and readouts at all 21 × 11 × 72 settings. `tools/check-ssm-applet-plants.mjs` shows that it catches 17 planted defects. Both run in vignette-precompute.yaml. The tarball fell from 5,128,715 to 3,084,520 bytes. NEWS got one Documentation bullet under a new development heading. DESCRIPTION is unchanged.

**Decisions:** none cross-cutting. Milestone-local: the user chose the applet over a GIF rebuild from a script (planned first at 1000 px), then one applet with octant points. The plan chose inline JavaScript over Shiny or htmlwidgets, and a Node check over V8 in testthat.
