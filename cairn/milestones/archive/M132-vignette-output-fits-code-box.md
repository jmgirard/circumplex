# M132: Rendered vignette output fits the website's code box

**Status:** done (2026-09-16, PR #165 https://github.com/jmgirard/circumplex/pull/165)

**Goal:** No output line in a pre-rendered vignette makes the website's code box scroll sideways.

**Outcome:** All nine vignette sources set `options(width = 77)`, so knitr output with its `#> ` prefix fits in 80 columns against a code box measured at 81. The seven pre-computed vignettes were re-rendered. The new `tools/check-vignette-width.R` reads every `#>` line of the seven renders and measures display columns against 80. It honors `<!-- vignette-width:exempt start -- <reason> -->` ... `end` regions, and errors on a region with no reason, an unclosed or nested region, a region exempting nothing, or an empty domain. It reports per-file line and exemption counts. `.github/workflows/vignette-precompute.yaml` runs it after the staleness step. The one exemption holds the `cx =~` and `cy =~` lavaan loading lines in `sem-based-ssm-analysis`. The `ssm_ci_accuracy()` summary heading became `Verdicts (c = 1, as estimated), Bradley (1978) liberal band, 95% Wilson CIs:` (76 columns), with its snapshot and width-ledger entry. The introduction vignette uses `linewidth = NA` in place of the deprecated `label.size = NA`. `tools/m132-planted-defects.R` plants four defect forms and two controls in each vignette (42 plants). NEWS.md records the heading and the width.

**Decisions:** An exempt region over wrapping the lavaan lines or raising the limit to 86. No guard for the two live vignettes, because one needs brms to render. The heading was reworded rather than raising the limit to 81. The two exempted lines still scroll, which the maintainer accepted at the gate as planned.

**Review:** Two passes. Pass 1 stopped on an amendment return for AC1 (its "23 lines are gone" clause contradicted the exemption) and AC6 (line numbers the marker shifted). Both were reworded and passed two fresh re-audits. Pass 2 ran the three-lens fan-out and passed all seven criteria: tests FAIL 0 / PASS 10743, check 0 errors, 0 warnings, 0 notes, guard green, 42 of 42 plants, re-render up to date, all six PR checks green. At the gate O1 (a marker with no reason passed the reason pattern) and O2 (NEWS gave the wrong reason for the heading change) were fixed on the branch. P1, O3, O5, O6, O9 and O10 went to a new width-guard candidate row. O4, O7, O8 and O11 were rejected, and O12 (a work-log byte count of 157 for 156) was noted. No lesson added.
