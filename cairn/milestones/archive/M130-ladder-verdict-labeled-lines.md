# M130: The invariance-ladder verdict prints as labeled lines

**Status:** done (2026-09-15, PR #163 https://github.com/jmgirard/circumplex/pull/163)

**Goal:** A grouped `ssm_sem()` print shows the invariance verdict as short labeled lines, and the block fits the website's code box.

**Outcome:** `sem_verdict_facts()` builds the verdict's facts once, and `sem_format_verdict()` lays them out as a `Verdict:` line with indented `Test:`, `Result:`, `Also:`, `Contrast:`, `Profiles:` and `Instead:` lines. `sem_fit_ladder()` builds its stored verdict string from the same facts, so the string, the non-comparable warning and the `ssm_plot_contrast()` error are byte-identical to master. `sem_noncomparable_facts()` gives the cautions to both the facts and the fallback print for an object missing `required` or `alpha`. `sem_dcfi_note()` lost its out-of-scope branch: the `dcfi` and `cr` columns and the note print only when `dcfi_scope$in_scope` is TRUE and a rung has a `dcfi` value (D-059), and `dcfi_scope` records groups, estimator and plain-CFI fields. Every block line fits 77 and 80 columns in a UTF-8 locale. The SEM vignette sets `options(width = 77)` and is re-knitted, and its prose, the `ssm_sem()` roxygen and NEWS.md describe the new output. `tests/testthat/helper-ssm-sem-ladder.R` fits 14 cached ladder cases, which every new test reads.

**Decisions:** Verdict-first labeled lines (mockup C) over per-block headings; rebuild the facts in print rather than change the stored string; hide out-of-scope ΔCFI per D-059; width 77 in this vignette only. Two printed-text ledgers map master's block to the new lines, case by case.
