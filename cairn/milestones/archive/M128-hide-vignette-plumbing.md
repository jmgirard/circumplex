# M128: Vignettes show the package calls they teach, not the plumbing around them

**Status:** done (2026-09-15, PR #161 https://github.com/jmgirard/circumplex/pull/161)

**Goal:** A vignette reader sees the circumplex calls and model-fitting calls being taught, while the code that simulates data, assembles or formats display tables, or checks internals is hidden, and simulated data is loaded from the package by name.

**Outcome:** Three datasets ship under D-058. `data-raw/simulated_occasions.R` writes `simulated_occasions`: 200 persons at waves T1 to T3, with displacements 330, 355 and 20 degrees. `data-raw/simulated_growth.R` writes `simulated_growth` and `simulated_growth_origin`: 150 persons at waves 0 to 4, with shared person effects. They have help pages in `R/example_data.R`, `_pkgdown.yml` rows and NEWS entries. The advanced-visualization and growth vignettes load them with `data()`. Nine vignettes now hide data building, reshaping, draw loops, `stopifnot()` checks, `readRDS()` and `kable()` formatting. The prose names each object that a hidden chunk defines. The growth vignette shows `ssm_parameters_id()`, both `glmmTMB()` fits and single-wave `ssm_draws()` calls. The structure vignette writes out three `cpm_fit()` calls, and SEM shows `ssm_table(latent)` in a plain fence. `tools/vignette-echo-sweep.R` searches shown code for plumbing, with fixtures and a testthat test. Its modes are `--taught`, `--compare-taught`, `--hidden-names`, `--other` and `--self-test`. Branch-cut lists are in `devel/m128-echo-sweep/`.

**Decisions:** D-058 (datasets over `.rds` files). The plan gates chose to hide every flagged chunk, to show one `ssm_draws()` call with the loop hidden, and to keep kable over gt. One re-cut followed maintainer feedback. The implement gate chose one shared help page for the growth datasets. The AC8 amendment gate narrowed using-instruments to "no new prose-sweep finding over the branch cut".
