# M135: Vignettes are labeled by level and framed like the older ones

**Status:** done (2026-09-16, PR #168 https://github.com/jmgirard/circumplex/pull/168)

**Goal:** Every vignette states its level and opens and closes the way the three older vignettes do, and the website groups the vignettes by level in reading order.

**Outcome:** Each of the nine vignettes opens with a `**Level:**` line (Introductory, Intermediate or Advanced) that names the page to read first, then a `## 1. Overview` that names every section after it, numbered sections, and a `## Wrap-up` that names the next page or, on the three terminal pages, says no page follows and names a related page. The reading map lives in `tests/testthat/test-vignette-frame.R` as `frame_levels` and `frame_next`, and the test checks the Level line, the heading sequence, the Overview mentions, the Wrap-up cross-links in both directions, and the terminal-page wording. `_pkgdown.yml` gained a three-level `articles:` index and a navbar menu in the same order with `axes-reliability` added, diffed against `vignettes/` by `tools/check-pkgdown-vignettes.R`. No chunk or chunk output changed, and the seven pre-computed pages were re-rendered for the prose. NEWS.md has one entry.

**Decisions:** The plan gate chose a frame carried in each page over labels in the site index only. The implement gate put the frame checks in a testthat test and the pkgdown diff in a `tools/` script, because the diff needs the yaml package.
