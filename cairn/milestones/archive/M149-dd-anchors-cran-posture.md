# M149: Reference-route checks at the anchors, and the certificate file's CRAN posture

**Status:** done (2026-09-23, PR #184 https://github.com/jmgirard/circumplex/pull/184)

**Goal:** The test file asserts the certificate's double-double reference route against the committed exact values at all six committed cases. The help page states that the estimate depends on the machine. A decision records the CRAN posture of the certificate test file.

**Outcome:** In `tests/testthat/test-axes-certificate.R`, `cert_frozen` carries each anchor's `xi1` upper triangle, emitted by `devel/degeneracy-oracle/exact_oracle.R`. Five per-anchor tests call `cert_dd_vs_exact()`. Each asserts `v`, `v_naive` and `u` within half an ulp of the exact value and fails by name on a non-list return. Each skips on a `sig` or `xi1` mismatch and never calls `cert_record()`, so the case's brackets still run. A committed-values test asserts that every exact value sits farther from a rounding midpoint than a stated bound of `20 * p * kappa^2 * 2^-51` ulp. Its comment names three premises of that bound as unproven. Counterexample B's priced branch asserts `"uncertified"`. `?axes_reliability` says that on a severely ill-conditioned fit the estimate is a property of the fit as computed on the running machine. The anchor-list test runs on CRAN. No shipped behavior changed.

**Decisions:** D-063 keeps the certificate file's CRAN posture. The checks against exact truth, the committed-value checks and the contract checks run on CRAN. Five tests with no exact yardstick skip there. RR22's CI-only reading is rejected.
