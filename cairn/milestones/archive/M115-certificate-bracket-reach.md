# M115: Make the packaged accuracy bracket assert where the shipped pricing differs

**Status:** done (2026-08-30, PR #146 https://github.com/jmgirard/circumplex/pull/146)

**Goal:** Replace the frozen macOS pricing yardstick with a committed exact value, so the packaged bracket measures the running machine's own error instead of skipping wherever that machine is not the one the figures were frozen on.

**Outcome:** `tests/testthat/test-axes-certificate.R` now commits the exact `v`, `v_naive` and `u` per case as hi/lo double pairs (about 106 bits), emitted by `devel/degeneracy-oracle/exact_oracle.py` via `%a` and pasted from `exact_oracle.R` under `CERT_EMIT=1`, which prints matrix and exact values from one construction. `cert_true_error()` prices the running machine against them; `cert_bracket()` replaces every `skip()` with two asserting branches (at the floor: the machine's error is below what the floor certifies; above it: the [1, 1e3] bracket), so no case reports PASS having asserted nothing. Only the anchor-matrix half of the old precondition survives, compared as doubles rather than `%a` text and run before the shipped pricing so a differing machine skips rather than being told its refusal is a regression. Also: an assertion that the case list is non-empty, `cert_floor` writing the safety factor down instead of reading `axes_certificate_safety_factor` (so raising it 10→100 reddens 13 assertions where nothing reddened before), `cert_n` counting ratios formed rather than `cert_line()` calls, `sweep_ok`/`reach_ok` derived from their own loops' collected vectors, and counterexample B asserted against `axes_degeneracy_delta_star` rather than one machine's decades. Measured: all six cases assert on ubuntu, macOS and Windows with zero certificate skips; before, Windows reported nothing at all.

**Decisions:** none milestone-local. No D-entry: the exact-emission approach was a plan-gate choice recorded in the work log with its falsifier.
