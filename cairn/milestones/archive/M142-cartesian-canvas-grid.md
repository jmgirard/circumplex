# M142: A Cartesian-grid style for the circumplex canvas

**Status:** done (2026-09-20, PR #176 https://github.com/jmgirard/circumplex/pull/176)

**Goal:** Give `coord_circumplex()` a `grid = "cartesian"` mode that draws a plain rim, a labelled crosshair and no rings or spokes, and give `ggcircumplex()` that mode plus `angle_labels` (rim tick marks and labels carrying each angle in degrees), the canvas style of Nagy, Etzel and Lüdtke (2019, Figures 3 and 6).

**Outcome:** `coord_circumplex(grid = c("polar", "cartesian"))`, resolved by `circumplex_grid()` (the default pair reads as polar; anything else must be one of the two names, an explicit `stop()` naming `grid`) and stored on the ggproto. In cartesian mode `CoordCircumplex$render_bg` returns `cartesian_grid_grob()`: a 361-point rim polyline at the largest finite radial break (the M38 rim append guarantees one), two crosshair lines through the origin along displacements 0/180 and 90/270, and for every radial break strictly between `center` and the rim a tick and a signed label on each half-axis, all from `panel.grid.major`, `axis.ticks.r`, `axis.ticks.length.r` and `axis.text.r`; tick length and label gap ride in fixed-size viewports so every along-axis position is a plain npc value (`as.numeric()` on a grid unit sum is meaningless). A non-blank `panel.background` is drawn as a polygon clipped to the rim. `setup_panel_guides` sets the `r` and `r.sec` view-scale guides to `guide_none()` before the parent positions them. NULL amplitude labels (a `labels = NULL` scale) draw ticks and no labels. `ggcircumplex(grid, angle_labels)`: `grid` passes to the coord; cartesian mode adds `axis.ticks.theta`/`axis.ticks.r` lines (gray30, 5 pt and 4 pt); `angle_labels = TRUE` on text labels only formats them `<label> (<angle>°)` through `circumplex_angle_labels()` (rounded; `deg %% 360 == 0` written 360), adds `guide_axis_theta(angle = 90)` for radial rotation, and a `plot.margin` of `0.5 * font_size * max(nchar(lab))` pt; the default degree labels are untouched in format, rotation and margin. Validation `stopifnot(is_flag(), !is.na())`. Tests: grid validation; an AC2 grob walk by name and class on three canvases (public, coord-only with `center = 0.1`, trained rim 0.73); label formats for 0, 360, 11.4, 200.6 and `instrument = csip`; rotation read from the text grob's `rot`; theme elements; five-case seam identity of `layer_grob()` vertices and built data across grids; regressions for NULL labels, zero inner breaks and a filled background; two vdiffr snapshots. Roxygen (Nagy cited as "et al." and the degree sign described in words, since the Rd guard rejects `ü` and `°`), NEWS, DESIGN bullets.
