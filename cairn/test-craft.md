# Test craft

Verification-craft doctrine, graduated whole out of `cairn/LESSONS.md` by M104
(2026-08-22) under the maturation exit in the cairn tracking rulebook's
"Retiring a lesson". Each family below teaches transferable craft and had been
extended or consolidated at least twice before it graduated.

Read this file at plan time whenever the scope touches tests, guards, mutation
proofs, tolerances, fixtures, or CI checks — `cairn/LESSONS.md` carries the
pointer. Like `LESSONS.md` this is **current knowledge**: correct an entry in
place where it is proven false and mark the correction (`corrected M<NN>`);
never append a correction that leaves the wrong text readable. Not status, not
decisions. One family per line, so the file stays greppable.

Capped by this header rather than by `cairn_validate`, whose `LINE_CAPS` live in
the cairn plugin repo and not in this one: **under 35 lines and under 9,000
bytes**, set from the graduated size (26 lines / 7,293 bytes on 2026-08-22) plus
headroom for roughly one more family. Read with `wc -l -c` at ROADMAP hygiene
passes — the same hand-checked treatment the cairn tracking rulebook's "Weight
caps" gives `ROADMAP.md`'s and `LESSONS.md`'s byte budgets. Over either figure the
remedy is retirement or compression here, never "let it grow": an entry that stops
earning its line is trimmed or deleted the same way it would be in `LESSONS.md`.

- 2026-07-12→2026-08-18 (M13 family): **a guard has teeth only if you break the guarded line and see it fail — prove by mutation, never by eye.** test re-types the production expression (M13); assertion implied by the defect (M33); fixture sits where the bug is invisible (M35) or is impossible — build from ONE population, assert estimates near truth (M61); guard never matched (M40); probe narrower than what it probes — scope it, `grep -F` metacharacters, verify ranges by first AND last line, flatten wrapped prose (M43, M57); guard checks fewer dimensions than the indexing; mutation reddens for the wrong reason — assert the quantity the path determines (M59); seam mock routes past the condition — assert it unmocked (M62); two sides built by the SAME line catch nothing common-mode — pin one to a literal (M65); a mutation certifies only the REVERT — pin verb stems, pair negatives with positives, never author-certify (M66); sides sharing an ORIGIN cannot disagree — name each's independent origin (M72); `pdftotext` proves in-FILE, not on-PAGE — render and look; after correcting an anchored fact, `grep -rn` the OLD string repo-wide (M73); a suite that never visits the threshold kills no mutants — pin 1.05×/0.95× the floor, verify reddening (M89); vdiffr baselines count only on the CHANGED path (M38); a block-EXTRACTION helper certifies content, never PLACEMENT — pin the container header and seam bytes too (M94).
- 2026-08-14→2026-08-17 (M82 family): **the mutation harness itself lies.** `git checkout --` restores from the INDEX, discarding uncommitted work — commit before mutating, restore by copy, re-hash after every restore (M82, M92); `gregexpr` returns −1 with length 1 — assert the ARTIFACT changed (blob hash), never that the edit call returned (M82); `on.exit` restores don't survive a hard kill — one mutant per invocation, mutate only committed files (M88); a DOTALL regex spans ACROSS call sites — anchor multi-line edits line-by-line, re-read aimed sites before recording success (M87); a top-level mutant in a `sys.source()`d script executes at load — plant inside a function never called (M87).
- 2026-07-26→2026-08-18 (M59 family): **a tolerance calibrated on one machine is not a tolerance — derive the bar from the DISCRIMINATION required, with headroom for platform noise.** covr instrumentation perturbs optimizer results — green check ≠ green coverage job (M59); testthat 3e `tolerance` is RELATIVE — write `expect_lt(abs(x - y), tol)` and pin the measured value, not the rounded quote (M61, M92); prose bounds pinned off one run fail their own re-run — state them comparatively ("under 5% of the estimate's own SE") (M64); a criterion fencing an RB/RR artifact's CONTENT must be satisfiable before it archives (IP4) (M64); a committed fixture from the authoring machine makes bit-exactness locally unfalsifiable — gate exact replay on the environment the fixture RECORDS, keep an ungated loose bar, never environment-gate pure arithmetic over a frozen file (M68) — a committed output SNAPSHOT is the same fixture (CI measured 3rd-decimal platform deltas; M94); too LOOSE fails the other way — check the alternative actually fails at the bar (M69); and a pin added BESIDE an existing assertion inherits its neighbour's job — a pin ten times tighter than the bracket beside it reddens on the very platform difference that bracket exists to price (M118).
- 2026-07-26 (M60 family): **replacing a narrow check with a general one drops what the narrow one refused by ACCIDENT — enumerate the old gate's incidental rejections, re-assert each** (`anyNA()` never rejects `±Inf`) (M60); a clause suppressing a false case suppressed a true one — check which side of the filter the comparand sits on (M67); exempting a syntactic slot fails open where it means something else — enumerate its POSITIONS (M83); an exemption INFERRED from guarded data is evaded by any unenumerated value — declare it as an argument (M86); a REPLACEMENT guard can be WEAKER — `sort()` drops NA names under `na.last = NA`; a regex constant in an anchored pattern must keep its own `(...)` (M98); and what it ignored INERTLY it now ADMITS — a null value an equality passed over trips an exclusion, turning a neighbour load-bearing (M99; again M100).
- 2026-08-07 (M75 family): **an expected value derived from the implementation's own expression can never disagree with it.** Sweep the SOURCE's inventory, not consumers' claims (M75); derive expectations from the REQUIREMENT, or extract the shared rule as a function both call and fence ITS contract (M76) — prove callers call it: grep the predicate's BODY, mutate it to a constant (M78); a phrase that can arrive as DATA needs the rendered line asserted with its label prefix (M78); an "accepted, and nothing else" criterion makes the recognizer the set's definition, tested as a PARTITION in both directions (M79); converse: two derivations agreeing on today's data are not one set — a shared NAME is not a shared DEFINITION; extract the base, layer the filters (M83); a message quoting its input satisfies any match on that input — assert phrases only the code COMPOSES (M88).
- 2026-08-18→2026-08-21 (M95 family): **a check can pass by not checking.** A cancelled run is `completed` without being a verdict, so a gate reading "most recent completed run" false-fails when `cancel-in-progress` kills a job. Three no-ops: macOS has no `timeout`, so `timeout N gh pr checks --watch` fails while a trailing `echo` reports success; YAML 1.1 reads a bare `on:` as TRUE, so `read_yaml(f)[["on"]]` is NULL and a trigger assertion passes vacuously (M95); and zsh never word-splits unquoted `$FILES`, so a multi-file grep reads nothing and passes (M97). A guard proving a NEGATIVE over open-ended grammar loses to the next construct (M96): compare PRODUCED output to a committed expectation, out of band and injectively. A GREEDY span extraction overruns once added text repeats its terminator — bound a span by its NEXT marker, and report bytes and chars separately, since a reader comparing one to the other will call a correct figure wrong (M102); and a YAML plain scalar cannot hold `": "`, so a fixture meant to be VALID parsed as broken and mimicked the broken cell's signature — parse every fixture locally before driving it (M102). A guard asserting two things sit TOGETHER is only as tight as the span it calls together: splitting an Rd page on `. ` gave a "sentence" of 2,635 characters, because Rd sections end on `.}` and `}` rather than period-space, so a figure-beside-its-coefficient claim was really a figure-somewhere-in-this-section claim and the planted defect stayed green — bound adjacency by a measured character window, and count OCCURRENCES of the thing, never the chunks it fell into (M110). A non-empty-domain guard (M108) protects only what it actually feeds: M114 asserted its band non-empty and then selected the band's members by round-tripping them through `format()`, which pads a numeric VECTOR to a common mantissa width — `format(1e-9)` is `"1e-09"` while `format(c(1e-9, 1.25e-9, 3e-9))` starts `"1.00e-09"` — so a widened band could pass the guard and run the assertion loop zero times; select by index or logical mask, never by formatted text. And a HAND-WRITTEN stub of a return whose consumer maxes over its fields cannot notice a field being added (`max(1, 2, NULL)` is 2) — pin the stub's field set to the production sentinel (M114).
